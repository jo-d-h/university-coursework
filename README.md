## 파일 열기와 실행

- **C/C++와 OpenGL** — 해당 과목의 솔루션 파일을 Visual Studio에서 엽니다. 2022년 0926 실습은 C++ 도구 집합 v142, 이후 확인한 프로젝트는 주로 v143을 사용합니다. OpenGL 실습의 packages.config에는 NuGet 의존성 버전이 기록되어 있습니다. 일부 솔루션은 참조하는 프로젝트 파일이 빠져 있습니다.
- **Python과 Jupyter** — 과목별 폴더에서 스크립트나 노트북을 엽니다. 일부 예제는 WAV, 이미지, CSV 등 별도 입력 파일과 로컬 또는 Colab 경로를 사용합니다. 모든 입력 파일이 이 저장소에 들어 있는 것은 아닙니다.
- **웹서버와 Java** — Team010은 PHP와 MySQL, WaitingList0609는 Java Swing과 MySQL을 사용합니다. 각 프로젝트의 SQL과 연결 설정은 수업 당시 자료입니다.
- **Roblox** — .rbxl 파일은 Roblox Studio에서 엽니다.

이 저장소는 수업 자료 보관용입니다. 각 예제의 빌드와 실행은 개별적으로 확인해야 합니다.
