1. 프로젝트 개요

"밥도둑" 프로젝트는 동의대생의 교내 식사 문제를 해결하기 위해, 분산되어 있는 식당 정보를 한곳에 모아 제공하고 실시간 리뷰 및 평점 정보를 활용하여 보다 편리하게 식사 결정을 내릴 수 있도록 하기 위해 만들어졌다. 이 프로젝트는 HTML/CSS/JavaScript 기반의 프론트엔드, PHP와 MySQL 기반의 백엔드, 그리고 직접 수집한 리뷰와 이미지 데이터를 활용한 데이터베이스로 구성되어 있다.


2. 데이터 설명

이 프로젝트에서 사용된 데이터베이스는 총 5개의 테이블로 구성되어 있으며, 각 테이블의 구조와 역할은 아래 표와 같다.

2.1 users 테이블 – 회원 계정 정보 저장

이름타입역할
idINT회원 고유 ID
usernameVARCHAR(50)로그인용 사용자 ID
emailVARCHAR(100)회원 이메일
nicknameVARCHAR(50)사이트에서 표시되는 닉네임
passwordVARCHAR(255)비밀번호 - 암호화 저장(bcrypt)
is_adminTINYINT관리자 여부(1=관리자/0=일반 사용자)
created_atTIMESTAMP계정 생성일

3. 화면설계

3.1 메인 페이지

  • 검색창

  • 메뉴 및 장소 선택 버튼

  • 인기 랭킹 및 혼밥랭킹

3.2 검색 페이지

  • 검색 결과 리스트(가게 정보 표시)

3.3 랭킹 페이지

  • 각 랭킹 별 가게 순위 및 정보(사진, 위치, 메뉴, 평점)

3.4 가게 상세 페이지

  • 가게 기본 정보(사진, 메뉴, 위치, SNS, 영업시간, 혼밥추천)

  • 평점 및 리뷰 섹션

3.5 리뷰 작성/수정 페이지

  • 한줄평, 별점, 사진(선택) 및 내용 입력

3.6 로그인 페이지

  • 아이디 및 패스워드 입력

  • 회원가입 링크

3.7 회원가입 페이지

  • 아이디, 이메일, 닉네임 및 패스워드 기입

3.8 마이 페이지

  • 사용자 정보 표시

  • 작성한 리뷰 목록 표시

  • (관리자 계정일 경우) 관리자 페이지 이동 버튼

3.9 개인정보 수정 페이지

  • 닉네임, 이메일 및 패스워드 수정

3.10 관리자 페이지(관리자 계정에서만 접근 가능)

  • 회원 목록 표시 및 관리자 설정, 강제 탈퇴

  • 리뷰 목록 표시 및 강제 삭제


4. 기능목록

4.1 검색 기능

  • 가게명, 메뉴명, 검색 키워드 기반 다중 조건 검색 기능 구현

  • 검색 결과에서 가게 이미지, 위치, 평점, 영업시간 등의 요약 정보를 즉시 확인 가능

4.2 랭킹 기능

  • 네이버 리뷰와 사이트 자체 리뷰를 통합한 평점 및 리뷰 수 기반 랭킹 산출

  • 평점을 기반으로 한 맛집 랭킹, 혼밥 추천 리뷰 수를 기반으로 한 혼밥 랭킹 2가지의 랭킹 제공

4.3 리뷰 기능

  • 사이트 내 리뷰 작성, 수정, 삭제 기능 제공

  • 별점, 한줄평, 상세 후기, 사진 업로드 기능 포함

  • 사진 업로드 시 파일 형식 제한 적용하여 안정성 확보

  • 리뷰는 최신순으로 정렬되며, 가게의 평균 평점 및 리뷰 수 자동 반영

4.4 혼밥 추천 기능

  • 리뷰 작성 시 한줄평에 '혼밥하기 좋아요' 선택 시 혼밥 추천 수(solo_good_cnt) 증가

  • DB에서 혼밥 가능 여부(shop_alon)가 1로 설정된 가게만 혼밥 추천 O로 표시

  • 혼밥 지표는 혼밥 랭킹 페이지 및 가게 상세 페이지에서 표시

4.5 회원 기능

  • 회원가입, 로그인, 로그아웃 기능 (비밀번호는 bcrypt로 암호화 저장)

  • 세션 및 쿠키를 이용한 로그인 상태 유지

  • 마이페이지에서 이메일/닉네임/비밀번호 수정 가능

  • 사용자가 작성한 리뷰 목록 조회 및 수정/삭제 가능

4.6 관리자 기능

  • 회원 목록 관리: 관리자 권한 부여/해제, 사용자 강제 탈퇴 기능 제공

  • 사이트 리뷰 전체 조회 및 부적절한 리뷰 강제 삭제 기능

  • 리뷰 삭제 시 가게의 평균 평점, 리뷰 개수 등 통계 값 자동 갱신

4.7 데이터베이스 백업 및 업데이트 기능

  • mysqldump를 활용한 DB 전체 백업 기능 구현

  • 관리자 페이지에서 최신 백업 파일 업데이트 기능 제공

  • 웹 환경에서 버튼 클릭만으로 안전하게 DB 관리 가능하도록 구현


5. 점검 시나리오

5.1 시나리오 1 : 검색 기능

  1. 메인 페이지에서 사용자가 '컵밥'을 검색한다

  2. 검색 페이지에서 표시된 컵밥 매장을 확인하고, 표시된 매장 중 한 곳을 클릭한다

  3. 가게 상세 페이지에서 표시되는 기본 정보들이 올바른지 확인한다(SNS 링크, 메뉴 사진, 영업시간 등)

5.2 시나리오 2 : 회원가입 및 리뷰, 랭킹 기능

  1. 메인페이지에서 오른쪽 상단의 마이페이지 버튼을 클릭한다

  2. 로그인 페이지에서 회원가입 버튼을 클릭한다

  3. 회원가입 페이지에서 필요한 정보를 기입하고 회원가입을 완료한다

  4. 가입된 계정으로 로그인 후, 평점이 없는 가게 중 한 곳을 선택한다

  5. 가게 상세 페이지에서 리뷰 작성 버튼을 클릭하고 리뷰를 작성한다(한줄평은 '혼밥하기 좋아요')

  6. 메인 페이지로 이동 후, 맛집 랭킹 및 혼밥 랭킹 페이지에서 리뷰 갯수 및 순위가 정상적으로 반영되었는지 확인한다

5.3 시나리오 3 : 마이페이지 및 관리자 기능

  1. 기존 로그인 된 계정에서 로그아웃 후, 메인페이지에서 오른쪽 상단의 마이페이지 버튼을 클릭한다

  2. 로그인 페이지에서 관리자 계정으로 로그인한다 (아이디/비밀번호: admin)

  3. 마이 페이지에서 개인정보 수정을 클릭하여 개인정보를 변경한 후 정상적으로 수정되었는지 확인한다

  4. 마이 페이지에서 오른쪽 하단의 관리자 페이지로 이동한다

  5. 관리자 페이지에서 사용자가 쓴 리뷰를 확인하고 강제 삭제를 수행한다

  6. 관리자 페이지의 사용자 관리 탭에서 사용자 목록을 확인하고 특정 사용자를 선택하여 관리자 부여 및 삭제, 강제 탈퇴를 수행한다

  7. 가게 상세 페이지로 이동하여 리뷰가 정상적으로 삭제되었는지 확인한다


6. 생성형 AI(ChatGPT 등) 사용 영역

  • php 코드의 데이터베이스 연동 기초 부분에서 도움 받음

  • 로그인 기능에서 쿠키와 세션 연동 과정에 도움 받음

  • CSS에서 아이콘 및 배경 일러스트 생성/적용에 도움 받음


7. 데이터베이스의 수집

  • 음식점 리스트의 가게 기초정보는 네이버 지도, 카카오맵, 에브리타임, 배달의 민족에서 수집

  • 가게 이미지는 직접 사진 촬영 및 저작권 없는 이미지로 수집

  • 리뷰 데이터는 네이버 지도에서 웹크롤러 프로그램을 이용해 수집
