제안서 내용

1. 프로젝트 개요

동의인들이 이 정보들을 활용하여 동의대 음식점이 평점들을 확인하여, 맛있고 만족도 높은 식사를 할 수 있는 정보를 제공하기 위해 만들어짐.

2. 데이터 설명

2.1 음식점 데이터 - 메인 페이지, 검색 페이지, 랭킹 페이지에 사용

가게명, 업종공식SNS, 네이버 평점, 네이버 리뷰수, 배민평점, 배민 리뷰수, 혼밥여부, 위치

2.2 리뷰 데이터 - 랭킹, 상세 페이지에 사용

블로그 리뷰, 네이버 리뷰, 가게 이름, 전체 평점, 방문자 리뷰개수, 작성자, 사진 링크, 어떤점이 좋아요

3. 화면설계 ※ 화면별 (개수?) 평가

1) 메인화면
2) 검색 결과 페이지(조건문)
3) 랭킹 페이지 (전체 / 혼밥)
4) 식당 정보 페이지
5) 로그인/회원가입 페이지
6) 개인정보 페이지

4. 기능목록 ※ 기능항목별 평가시나리오

4.1 메인 페이지

- 회원가입/로그인
- 검색 기능
- 메뉴/장소/랭킹 링크

4.2 검색 페이지

- 메인페이지에서 장소, 메뉴 버튼을 누르거나 검색창에서 검색하였을 때 표출되는 화면
- 검색할 때 조건문 이용하여 필터 걸어서 해당 조건에 해당하는 음식점만 표출

4.3 랭킹 페이지

- 메인페이지에서 맛집랭킹 / 혼밥랭킹 버튼을 눌렀을 때 표출되는 화면
- 한 페이지 내에서 맛집랭킹 / 혼밥랭킹 둘 다 표출

4.4 음식점 페이지

- 메인페이지, 검색페이지 등에서 가게 버튼을 눌렀을 때 표출되는 화면
- 가게 기본 정보(전화번호, 영업시간 등) 표시
- 화면 하단에 사용자가 남긴 리뷰 조회

4.5 리뷰 작성/수정 페이지

- 음식점 페이지에서 리뷰 작성 버튼을 눌렀을 때 표출되는 화면
- 가게 리뷰 작성 창
- 별점/좋았던 점 내용

4.6 로그인 / 회원가입 / 개인정보 페이지

- 로그인/회원가입 기능
- 개인 정보 설정/수정
- 사용자 계정 관리
- 작성한 리뷰 관리

5. 페이지 관리

5.1 관리자 계정 구현

- 회원목록 조회/삭제 기능
- 강제 탈퇴 기능
- 관리자 권한 부여
- 전체 리뷰 조회/삭제

5.2 사용자 계정

- 탈퇴 기능
- 리뷰 수정/삭제 기능
